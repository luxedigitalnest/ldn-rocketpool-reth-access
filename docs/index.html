Read before using rETH

What direct minting means

ETH is deposited through the current Rocket Pool deposit contract to receive rETH if the protocol accepts your deposit. Rocket Pool’s documentation explains minimums, queues, fees and liquidity constraints. This tool never calls a payable deposit method.

Official liquid staking guide

Risk and verification

rETH is a liquid-staking token. Smart contract, validator, redemption-liquidity, price and protocol upgrade risks remain. The protocol rate is not a promise of an exchange-market rate. Independent verification is essential.

Official contract registry reference

Accessibility and honest scope

This volunteer prototype is usable with a keyboard, screen reader labels, high contrast, status announcements and reduced-motion preferences. It does not ask for a wallet, simulate or send a real deposit, guarantee a mint, display a financial recommendation, or imply endorsement by Rocket Pool.
